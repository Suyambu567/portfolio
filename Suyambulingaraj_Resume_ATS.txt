02 | Tamil BPE Tokenizer - Tamil NLP
Python, Byte Pair Encoding, Tamil Unicode, YAML, JSON - github.com/Suyambu567/Tamil-BPE-Tokenizer
- Tamil is agglutinative and composes each written character from a consonant plus a dependent vowel sign, so a naive tokenizer splits inside grapheme clusters and yields pieces that are not linguistic units, while word-level tokenization explodes the vocabulary.
- Implemented Byte Pair Encoding from first principles in plain Python with no tokenizer library: vocabulary construction, adjacent-pair frequency statistics, best-pair selection and iterative merge application, the encoder that replays learned merges over unseen text, the decoder, JSON merge-rule persistence with Unicode preserved, a Tamil Unicode validator over the U+0B80-U+0BFF block, token-to-ID vocabulary mapping, and YAML-driven config for reproducible runs.
- Trained on a demonstration corpus for 50 merges: the earliest rules learned join a consonant to its pulli and then to a following consonant, recovering Tamil's own orthographic units from frequency alone with no grammar encoded; encoding unseen text exposes the single-token memorisation that overfitting a small corpus produces.

03 | Fake User Detection - Machine Learning / NLP
Python, Scikit-learn, XGBoost, Random Forest, TF-IDF, FastAPI, Pydantic, JavaScript - github.com/Suyambu567/FAKE_USER_DEC
- Detecting fake social profiles from account metadata is a class-imbalanced binary classification problem in which accuracy alone is uninformative: a majority-class guesser already scores well above 50%, so every figure is reported against that baseline.
- Engineered profile, behavioural and textual features and encoded them in a fitted ColumnTransformer combining StandardScaler, TF-IDF over the bio and one-hot encoding; applied class-imbalance handling only after the train/test split; trained XGBoost with imbalance-strategy selection, and added a test asserting the training and serving feature frames are identical column for column, since both call one shared feature-building function; served it through a FastAPI service with Pydantic validation and model-version checking, and exported a smaller Random Forest to JSON re-implemented in vanilla JavaScript to run in-browser with no backend.
- Reached 0.9409 accuracy against a 0.6337 majority-class baseline, a lift of +0.3072, with F1 0.9179, ROC-AUC 0.9331 and 5-fold cross-validation 0.9400 +/- 0.0018 on 10,000 held-out profiles; the 256 KB in-browser model scored 0.9342 against a 0.6312 baseline. A control run on randomly shuffled labels scored 0.5110 against a 0.5045 baseline, confirming signal rather than leakage. Both models are evaluated on synthetic data, not a sample of real accounts.
