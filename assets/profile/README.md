# Profile photos

Drop up to three photos here. The home page picks them up automatically —
no HTML change needed:

| File | Used for |
|---|---|
| `photo-1.webp` (or `.jpg` / `.jpeg` / `.png`) | Main hero photo + About ID card |
| `photo-2.webp` | Second angle in the hero photo matrix |
| `photo-3.webp` | Third angle in the hero photo matrix |

- Portrait orientation works best (about 4:5). Keep each file under ~300 KB
  (webp at ~1000 px tall is plenty).
- With 0 photos the hero shows the animated HUD avatar; with 1 photo a single
  portrait; with 2–3 photos the matrix plus a Matrix/Portrait view toggle.
